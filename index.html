🍎 Install on iPhone / iPad
Save PulseLog to your home screen — works like a native app, no App Store needed.
1
Open this file in Safari (must be Safari, not Chrome)
2
Tap the Share button (square with arrow ↑) at the bottom of Safari
3
Scroll down and tap "Add to Home Screen"
4
Name it PulseLog and tap Add — done! ✅
⌚ Apple Watch
PWAs cannot run natively on Apple Watch. Options:
A
Use the iPhone app on your wrist via iPhone mirroring (iOS 18+)
B
For a true Watch app, the code needs to be converted to Swift / WatchOS in Xcode — ask a developer or use a service like Bravo Studio
🤖 Install on Android
Install directly from Chrome — no Play Store needed.
1
Open this file in Chrome
2
Tap the three-dot menu (⋮) in the top right
3
Tap "Add to Home Screen" or "Install App"
4
Tap Install — the app icon appears on your home screen ✅
🌐 Share the app with others
To share a link instead of a file, host it for free on one of these platforms:
1
GitHub Pages — free, upload the HTML file to a repo and enable Pages
2
Netlify Drop — drag and drop the file at netlify.com/drop — instant URL
3
Vercel — vercel.com, connect your GitHub repo, auto-deploys
